ORGANIZACION DE CARPETAS

src/
├── api/            # Configuración de Axios e interceptores para el Token JWT.
├── assets/         # Imágenes, logos y estilos globales (CSS/Tailwind).
├── components/     # Componentes reutilizables (Botones, Inputs, Cards).
├── context/        # Aquí manejaremos el Estado Global (AuthContext).
├── hooks/          # Custom hooks (ej: useAuth, useQuestions).
├── layouts/        # Estructuras de página (Navbar + Footer).
├── pages/          # Vistas completas (Home, Login, QuestionDetail).
├── routes/         # Configuración de React Router y Rutas Protegidas.
└── utils/          # Formateadores de fechas o validadores.
